# AgenticOrg (retired)

The AgenticOrg UX Director integration was retired on 2026-11-03 and replaced by the in-house UX Director. It uses Claude models, rubric scoring and one-click publishing, with no external HITL approval.

See **[UX_DIRECTOR.md](UX_DIRECTOR.md)** for configuration, the pipeline, scoring and troubleshooting.

Reports created by AgenticOrg remain viewable as read-only legacy reports. They can't be published; run a new analysis instead. The `AGENTICORG_*` environment variables are no longer read and can be removed from Render.
